# elkhoury_course04

Short description of the project: what it does and why.

## Installation

```bash
git clone https://github.com/emlyon-hids-python-2026/elkhoury_course04.git
cd elkhoury_course04
uv sync
```

## Usage

```bash
uv run scripts/demo.py
```

## Project structure

- `data/`: datasets (not tracked by git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/`: Python package
